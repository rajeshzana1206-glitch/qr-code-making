# LinkedIn QR Code Generator

A simple Python project that generates a QR code from a LinkedIn profile URL.

## 📌 Project Description

This project allows users to enter their LinkedIn profile URL and automatically generate a QR code.

When the QR code is scanned using a smartphone, it opens the LinkedIn profile directly.

This project was created to practice Python programming, user input, external libraries, and QR code generation.

## 🚀 Features

- Generate a QR code from a LinkedIn profile URL
- Accept user input through the terminal
- Save the QR code as a PNG image
- Simple and beginner-friendly Python project

## 🛠️ Technologies Used

- Python
- qrcode library
- Pillow
